你正在分析一个【已反编译好的 Android jadx 产物】：当前目录下的 sources/ 是极大的 Java 源码树。任务是只读逆向定位，绝不修改任何文件。

【铁律 —— 不遵守必然超时空转】
1. 先用 grep 工具（不是 bash！grep/find/ls 是独立工具，直接调）定位关键符号/字符串/类名，再 read 命中的那一个类。禁止 ls/cat 整棵树、禁止盲目 bash find 全盘。
2. 单次 read ≤ 200 行；文件大就先 grep 出行号，再定点读那一小段。
3. 【关键】一旦你已能用「相对路径:行号」证据回答问题，立刻停止探索，输出以「## 最终结论」开头的答案。不要为支线细节继续翻找。
4. 只写你实际 read 到、能引用 file:line 的结论；没读到/没定位到的一律明说“未证实”，绝不编造类名/包名/路径/机制。
5. 目标是最短路径：尽量在 ~12 次工具调用内收尾。每一步先想“这一步是否让我更接近能下结论”，不接近就换策略。
