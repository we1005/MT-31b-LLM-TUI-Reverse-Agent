# 混合后端·云端顾问 + 脱敏防火墙 — 交付与验证报告

> 落地了用户确定的架构：本地 35B 执行器**卡住时**，把困境报告**脱敏**后问云端大模型拿**思路**，思路回本地落地续跑。
> **总开关默认关**（`--consult-cloud`），不开则纯本地、绝不出网。设计见 `混合后端-云端顾问-实现方案.md`，本文只讲**交付了什么 + 怎么验证的**。

## 1. 交付清单

| 文件 | 动作 | 内容 |
|---|---|---|
| `src/redact.ts` | 新建 | 唯一出网收口：`redact`/`restore`/`leakScan`/`knownIdentifiersFromLedger`。可逆一致替换 + 正则兜底 + fail-closed 泄露扫描 |
| `src/advisor.ts` | 新建 | `createCloudAdvisor`→`(report)=>Promise<string\|null>`（redact→云端 generateText→restore）；`wireAdvisor` runtime 一站式接线 |
| `src/agent.ts` | +1 访问器 | `ledgerState()` 只读快照（供脱敏取"已知敏感标识符清单"）。**主循环零改动**——复用既有 `askStrategy`/`stuckIntervene` |
| `src/config.ts` | +字段 | `consultCloud`/`advisorBackend`/`advisorModel`/`advisorBaseURL`/`advisorApiKey`/`redactLevel`/`maxConsults` |
| `src/index.tsx` | +flag | `--consult-cloud`/`--advisor-backend`/`--advisor-model`/`--advisor-base-url`/`--advisor-api-key`/`--redact-level`/`--max-consults` |
| `src/runtime/{run-once,run-interactive,run-web-server}.ts` | 接线 | `wireAdvisor` → `askStrategy`；三种运行模式全支持。默认关时行为完全不变 |

**核心工程杠杆**：脱敏不靠不可靠的 NER 猜，而是用台账 `Ledger` 已 verbatim 存下的类名/方法/路径/grep pattern 作**确定性敏感清单**做**精确一致替换**（可逆、高精度），正则兜底 catch 清单之外的 URL/IP/key/绝对路径/包名/资源名。

## 2. 数据流（默认关；开 `--consult-cloud` 才走云端分支）

```
agent 原地打转(stall/readHopStall/exploration 硬止损)
  → stuckIntervene(agent.ts) → askStrategy(report)
      = createCloudAdvisor:
          report → 🔒redact(台账清单+正则, 分级0/1/2)
                 → fail-closed 泄露扫描(非空⇒中止出境返回null)
                 → onEgress 出境预览(透明日志)
                 → ☁️云端 generateText(方法论-only, 独立超时)
                 → restore(占位符→真值)
      → 思路注入 user 消息 + 重置卡住计数 → 本地续跑(云给方向,本地拿 ground truth 核验)
  云超时/不可用/泄露/缺key → 干净回退 null → 本地强制收尾(绝不阻塞/裸抛)
```

## 3. 分级脱敏旋钮 `--redact-level`

- **0**：只脱 URL/IP/email/绝对路径/高熵 key（**保留**混淆类名/包名——混淆名信息量低、利思路可落地）
- **1**：+ 包名 / 类名 / 方法名 / 资源名
- **2**（默认，最严）：+ 裸大写/混淆类标识符也 token 化

同一真值全程映射**同一占位符**（`<CLS_3>`），云端能连贯引用；`restore` 完美还原。`RedactionMap` 只在内存、请求级、**不落盘**。

## 4. 验证（≥5 题，实际 93 条断言，全绿）

### 4.1 `bun run test:redact` — 脱敏防火墙题库（37 条，离线确定性）
- **题1 泄露门(level2 fail-closed)**：含包名/类名/方法/URL/IP/key/绝对路径/grep-pattern 的真实形状报告，脱敏后**无任一真实敏感串残留**、leaks 空。
- **题2 还原门**：`restore` 把云端回复占位符 100% 还原、不误伤普通文本。
- **题3 一致性**：同真值多处出现→同一占位符（云端连贯引用）。
- **题4 分级**：level0 保留包名/类名、level1 连它们一起脱。
- **题5 正则兜底**：ledger 之外的内嵌 URL/IP/email/key/绝对路径也脱。
- **题6 fail-closed 有效性**：clean 里真残留敏感时 `leakScan` 必报出。
- **题7 restore 容错**：`< CLS_1 >`/`&lt;CLS_1&gt;`/裸 `CLS_1`/被揉坏的 `<CLS_1:...>` 都能还原。
- **题8 汇出质量**：不把 `java`/`com`/`get` 通用短词纳入清单（防过度脱敏毁可读性）。
- **题9 不串号**：`CLS_1` 的裸兜底不吃 `CLS_10`。

### 4.2 `bun scripts/test-advisor-agent.ts` — agent 循环 × 顾问接线（15 条，离线确定性）
- **题A**：`wireAdvisor` 配置产物——默认关→enabled=false/无 askStrategy；开→escalate=true+askStrategy 就位+maxConsults 生效+非法档位夹到 0..2。
- **题B**：手搓 fake 模型把 agent 逼到原地打转硬止损，验证 **THE SEAM**：卡住→`stuckIntervene`→调 `askStrategy`(收到 **raw** 报告)→注入思路→重置计数→**续跑干净收尾**（`## 最终结论`），SCORECARD `escalations=1`。

### 4.3 `bun run test:advisor` — 真实端到端（11 条，顾问=**本地 lemonade**，串行零外部出网）
把顾问后端指向本地 lemonade，跑**完整链路**（困境报告→脱敏→真实 LLM→还原思路）：
- 出境防火墙：真正发给 LLM 的 clean payload **无**明文包名/URL/IP/绝对路径/混淆类名；保留 22 个占位符结构、leaks=0。
- 全链路通：拿到非空思路、redacted/consulting/advice 事件齐、思路里**无残留未还原占位符**、真实标识符(C7671/C11960/checkVip/isPremium/包名)被正确还原回思路。耗时 ~67s。

### 4.4 真实 CLI 回归
`--once "…" --consult-cloud --advisor-backend lemonade` 在**不卡住**的正常任务上：顾问**启用但保持休眠**（无 consulting 事件）、正常收尾 exit=0。→ 开启开关不干扰正常运行；默认关时行为完全不变（typecheck baseline 3 不变、test-guards 30/30、无回退）。

## 5. 测试中发现并修掉的真 bug

- **level-2 行号抽象 `:<LN>` 破坏 restore**：真实 E2E 里 Qwen 把 `<PATH_1>:<LN>` 揉成 `<PATH_1:<LN>>`，`>`-锚定的 restore 正则匹配不到 → 思路里残留 `<PATH_1:<LN>>` 垃圾。**行号脱离已脱敏文件名毫无信息量**，去掉该抽象；并给 `restore` 加**裸内层 id 兜底 + 长 token 先还原**，彻底根治（题7/题9 固化）。

## 5之二、卡住求助的两条路：保留 + 互斥 + 用户可选

云端顾问**不替换**原有的人工求助,两者作为 `askStrategy` 的两种实现**并存**,由用户按 flag 二选一(互斥):

| flag | 卡住时走 | 交互模式 | --once 模式 |
|---|---|---|---|
| `--ask-when-stuck`(原有,保留) | **人工** | TUI 展示困境报告 → 用户粘贴思路续跑 | 停机 + 写困境报告 + exit=3,等外部 `--strategy "<思路>"` 重跑 |
| `--consult-cloud`(新增) | **云端** | 脱敏问云端顾问 → 自动拿思路续跑 | 同左(自动,无需人工) |
| 都不给(默认) | 原有强制收尾兜底 | | |

- 实现是**优先级回退链**而非替换:`askStrategy = advisor.askStrategy ?? (askWhenStuck ? 人工通道 : undefined)`（`run-interactive.ts` / `run-once.ts`）。没开 `--consult-cloud` 时,`--ask-when-stuck` 的人工路径**完全照旧**。
- **两个都传 → 云端优先**(用户已显式选了更强的自动路径),且 `index.tsx` 会**显式打一条互斥提示**说明本次走云端、忽略人工,不静默。

## 6. 用法

```bash
# 默认：纯本地，绝不出网（不加 flag 即可）
rev-agent --once "…" --workdir work/mt-jadx

# 开云端顾问（卡住才脱敏问云端；云端后端可 claude/openai/volcengine）
export ANTHROPIC_API_KEY=sk-...
rev-agent --once "追踪 X 的调用链" --workdir work/mt-jadx \
  --consult-cloud --advisor-backend claude --redact-level 2 --max-consults 3

# 自测/无外泄：顾问指向本地大模型（串行不出网）
rev-agent --once "…" --consult-cloud --advisor-backend lemonade
```

## 7. 诚实边界

- **未对真实外部云端(claude/openai/volcengine)做过 live 调用**——本机三种云 key 均未设置。架构 backend-agnostic（复用 `createLLM` 已支持的云后端），真实外部路径 = 换 `--advisor-backend claude` + key 即走；本文的 live E2E 用**本地 lemonade 当顾问**验证了除"真正 TLS 出网到外部"外的**全部链路**（脱敏/防火墙/generateText/还原/注入/续跑）。
- **脱敏是"确定性清单 + 正则兜底"，非全知**：ledger 之外、且不匹配正则的自定义敏感串（如某种私有格式）可能漏；fail-closed 扫描做最后一道网，命中即中止出境。level 2 已对裸类名兜底 token 化。
- 云端只给**方法论**（占位符级），本地始终用 `read_file`/`grep` 拿 ground truth 核验——云错了本地能证伪。
