# 混合后端：本地 35B 为主 + 云端大模型作「脱敏后可调用的思路 tool」— 深度分析

> 缘起（用户想法）：后端**同时**连云端大模型 API + 本地 35B；**敏感信息不上云**；本地模型解决不了时，**屏蔽/脱敏敏感信息后调用云端大模型获取「思路」**；云端相当于一个 **tool**，是获取信息/思路的途径，不是主执行器。
> 本文是**深度分析 + 诚实裁决**（含红队），不是鼓吹。研究集成了 Anthropic Advisor Tool、FrugalGPT/RouteLLM 级联、Gaze 可逆伪匿名 runtime、PlanTwin 脱敏网关、Casper/Privacy-Gatekeeper 等 2025–2026 资料。
> 合规：全程只读分析；本文结论恰恰是**收紧**而非放宽红线。

## 一句话裁决

**想法的架构直觉是对的**（把现有 `--ask-when-stuck` 的人工环自动化，云端只当顾问），**但朴素实现「先脱敏再自动发」守不住你的红线**——因为我们要发的【困境报告】按构造就是逆向产物的 **verbatim 转储**，脱敏它要么删到无用、要么必漏。**结论：值得做，但只能以「人仍是出境闸 + 默认关闭 + 每次显式审批 + allowlist 抽象 + 意图门控」的受限形态做；把它当「让人手动转发这件事更顺手」的便利，而不是「全自动云兜底」。**

---

## 二、定位：这不是新架构，是换一个回调的实现体

关键洞见（研究「本地代码集成点」）：**我们早已有这套机制，只差把「人」换成「云」。**

- `agent.ts:102` 已定义 `askStrategy?: (report: string) => Promise<string|null>`；
- 三种硬止损（stall / readHopStall / exploration，`agent.ts:581/614/639`）触发 → `stuckIntervene()`（`agent.ts:515-551`）调用该回调 → 拿到思路作为 user 消息注入（`agent.ts:528`）+ 重置卡住计数 + `maxEscalations`（默认 3）封顶；
- 交互模式把回调接到**人工粘贴**通道 `strategyChannel.ask`（`run-interactive.ts`）；`--once` 接到 exit=3 + `--strategy` 重跑。

所以「云端顾问」= 把 `askStrategy` 的实现体从**「人工粘贴」**换成**「脱敏 → 云 → 反脱敏」**。agent 主循环**零改动**。净新增：`src/redact.ts`（唯一出网收口）+ `src/advisor.ts`（复用 llm.ts 已有的 `claude`/`openai` 后端 + `generateText`，不走 agent 循环）+ config + 一个 `--consult-cloud` flag。

**行业验证**（研究「Advisor 模式」）：Anthropic 2026-03 的 **Advisor Tool**（beta）正是这个 executor/advisor 分工——便宜快的 executor 干活、卡住时叫更强的 advisor 给「计划/纠偏」（~400-700 token）；实测 +2.7% SWE-bench 同时 −11.9% 成本。**但直接用它的托管版会把整条 transcript（含所有反编译代码）转发给 advisor —— 直接违红线**，只能借模式、自建网关。

## 三、核心洞见（用户对的地方）：「抽象问题上云、具体数据留本地」

这是正确的北极星，也是所有隐私-协作范式（PlanTwin / Sanitize-and-Solve / Privacy-Gatekeeper）的共识：

> 云端只需要**思路/方法论**（如「混淆 getter 恒真的常见指纹与验证法」「多跳追踪断链时的反向定位策略」），**不需要**真实类名/方法体/包名。把问题**抽象**上去、思路拿回来，在**本地未脱敏的真码上落地 + 验证**。

这天然把「值钱且敏感的具体」留在本地，把「通用且无害的抽象」发出去。**而且它正好补 Round-3 暴露的短板**：硬骨头/元能力题上 35B 定位失败，强模型的**方法论**思路能补方向——但落地和核验必须回本地真码（接上我们的反幻觉/出处分级工作：云给方向、本地拿 ground truth 落地）。

**级联触发**（研究 FrugalGPT/RouteLLM/Speculative-cascade）：别信模型自报「我不确定」（小模型系统性过度自信、越难越自信、倾向在失败里递归硬刚）。用**行为级卡住信号**（我们已有的 stall/readHopStall/exploration + 重复同一 tool 调用 + 预算耗尽）当闸门，自评只作辅助。

## 四、⛔ 红队裁决：朴素版「不通过」

红队（对现有代码逐行审）给出 **不通过**，六条硬伤：

1. **【困境报告】按构造就是逆向产物 verbatim 转储。** `buildStuckReport`（`agent.ts:492-508`）拼的是 `goal` + `renderChainGraph()`（跳 = 类.方法→类.方法 | file:line，**全 verbatim**）+ `render(3000)`（已读类 path + 已搜 grep pattern）。而 `ledger.ts:12` 的设计铁律明写「**verbatim，类名/方法/行号/URL 原样存，绝不 LLM 转述**」。→ 这份 payload 天生是原文，脱敏它**要么删空（失去让云给下一步的信号）、要么漏**，二者不可兼得。
2. **grep pattern / 文件路径 / goal 是高价值且极易漏判的泄露点。** `grep "checkVipValid"` / `grep "com.company.license.LicenseChecker"` 一条就同时暴露「我在找什么（破 VIP）」+「目标是谁（包名）」；jadx 输出路径 `work/mt-jadx/sources/com/mt/...` 直接点名目标；`goal` 首行常含「逆 MT管理器 2.14.5 MOD 破解版 VIP 校验」。
3. **代码内嵌字符串常量最危险**：硬编码 URL/host/license key/endpoint/base64 blob——逆向最想找的东西、最不像 PII、denylist 正则和 35B 都极易漏，一旦作为 evidence 出境就整段泄露。
4. **结构指纹无法脱敏**（Narayanan-Shmatikov 图再识别 / arXiv 2208.12553）：就算把标识符换成 `CLASS_A`，调用图拓扑 + 方法数 + 字符串分布对某个 APK 近乎唯一；云端（或其日志/传票）可凭结构反推目标。**改名 ≠ 匿名，只匿了名字没匿形状。**
5. **意图本身违 TOS + 你自己的红线。** 即使抽象化，请求实质仍是「协助追踪/绕过某 app 许可校验」= 请求商业云协助规避 TPM，违反 Anthropic/OpenAI Usage Policy；更违背你自订的 `compliance_redlines §5`「复杂分析才发云、且只发**摘要+hash**、不发完整代码」——困境报告是 verbatim 图+file:line，不是 hash。
6. **自动化砍掉了当前唯一可靠的防火墙 = 人。** 现状「人把报告手动贴给强模型」——人能逐字过目/删改/决定发不发。用自动脱敏器替掉它，等于在**最敏感的出境动作**上反而取消了 `append_note` 那种弹审批。而让**正卡住的 35B**（此刻恰恰能力不足）自己做「高召回脱敏 NER」= 让最弱环节守红线，漏判静默且无界。

**可行性补刀**：脱敏是高召回 NER + 语义判定任务，35B 对自定义标识符、字符串常量、混淆名 vs 真敏感名的区分会有大量 false negative；且困境报告是**代码拼的、不是模型生成的**——要么让模型出境前重写（增延迟/不可靠/破坏 verbatim 原则），要么上确定性正则（无语义、必过删或漏删）。

## 五、若仍要建：唯一可辩护的设计（受限形态）

把红队 topFixes + 研究（Gaze 可逆伪匿名 runtime / LLM Guard 双向 Vault / PlanTwin 四层网关）落成七条硬约束：

1. **人做出境闸，不自动发。** 云工具 = 「生成脱敏草稿 → 摊给用户看 diff/预览 → 显式审批后才出境」，复用 `note.ts` 的 `classify:()=>'ask'` 弹审批范式。**默认关闭、永不静默发送、每次显式批准。**
2. **出境 fail-closed + 离 lemonade 串行热路径。** 严格 timeout；云不可用即回退到现有 exit=3/halt 等 `--strategy`，**绝不阻塞 lemonade 单并发链**（memory #17 铁律）；云调用走独立通道。
3. **allowlist 而非 denylist，绝不发 verbatim ledger。** 只发**模型主动构造的抽象结构**（不透明 node id 的邻接关系 + 抽象问题），**不发** goal 原文 / file:line / grep pattern / 读到的代码行。即便如此仍保留人工审查（结构仍可指纹）。
4. **出境前强制泄露扫描 + 硬阻断 + 全量审计。** 正则 + 熵扫 payload 里的包名模式（`^([a-z][a-z0-9_]*\.)+\w+$`）/ URL/IP/邮箱 / 高熵串（疑似 key）/ 绝对路径，命中即 block（fail-closed，宁可过删）；每一字节出境全量落审计日志。参照 **Gaze SafetyNet**（独立只读 pass 扫漏网，命中即临时 token 化或直接 redact 放行）。
5. **provider + 意图双门控。** provider allowlist（**无 Doubao**；Anthropic/OpenAI 仅在 zero-retention / 企业条款下，且明确不进训练集）；加意图分类器——`goal` 含 bypass/crack/破解/VIP/绕签名 时**禁止出境、强制路由本地-only**（对齐 §5 与 TPM 法）。
6. **云思路降权为「假设」而非「权威」。** 别像现在 `stuckIntervene` 那样清零全部计数 + 满预算 + 命令「严格按此」。给云 hint **独立小预算**、标 provenance、要求本地 ledger 交叉核验后才采信——防坏思路拿满额预算烧、防能力退化。
7. **可逆映射只在内存、单会话、不落盘。** 参照 Gaze `SensitiveSnapshot`：占位符→真值映射封装为本地签名 snapshot，云侧永远拿不到；映射丢失变成**不可逆**（而非泄露原文）；每请求可轮换 node id 削弱跨请求关联（牺牲多轮连贯性——明确权衡）。**映射落盘 = 静态再识别密钥，绝不。**

### 分级脱敏旋钮（config `advisorRedactLevel`，默认取保守档）
- **level0**：只去路径 + 密钥（混淆名 `Cxxxx` 本身近乎无意义，保留能让思路可落地）——**风险高，不建议**。
- **level1**：连包名/类名也 token 化。
- **level2（默认）**：只发抽象图结构 + 「已试过什么」，零标识符。
> 鉴于红线是**绝对**的，默认 level2；且无论哪档，「脱敏是**降**风险、不是**消除**风险」必须写进 UI 提示——反编译代码的 string literal / import / 罕见 API 用法 / stylometry 对知情攻击者仍可再识别（arXiv 2208.12553 证明 k-anonymity 一般不可计算）。

## 七、分阶段落地 + 测试（测「不足」）

| 阶段 | 交付 | 怎么测 |
|---|---|---|
| P0 | `redact.ts` + 出境泄露扫描 | **红队测脱敏**：构造含包名/URL/key/路径/grep-pattern 的困境报告，跑脱敏，人工 + 正则双查「是否有一个真敏感串漏出」——**漏一个即不通过**（fail-closed 验收） |
| P1 | 审批门 + `--consult-cloud`（默认关） | 人工确认「每次出境都弹审批、能预览 diff、能取消」；默认不发验证 |
| P2 | `advisor.ts` + 意图门控 | 意图门控：破解 goal 必须被拦回本地-only |
| P3 | 端到端 A/B（受限形态） | **本地-only vs 本地+云顾问**：同一批 Round-3 硬骨头题，比「介入后是否提升定位/降幻觉」——但**只用抽象/公开题材做 A/B，不用真盗版 APK 出境** |

> ⚠️ A/B 有陷阱（研究）：云自动升级一旦变便宜，eval 指标会变成测**云能力**而非本地 35B，掩盖本地回归。必须始终保留纯本地 baseline，且顾问思路标 provenance，事后能区分「本地能力 vs 云兜底」。

## 八、结论与建议

- **用户的架构直觉对**：executor/advisor 分工成熟（Anthropic Advisor Tool 背书）、集成成本极低（换一个回调）、「抽象上云/具体留本地」是正确北极星，且能补 Round-3 硬骨头短板。
- **但朴素「自动脱敏后发」不通过**：困境报告是 verbatim 逆向产物，脱敏与有用性零和；结构指纹可再识别；抽象化的破解意图上商业云仍违 TOS + 你自订 §5；自动化砍掉了唯一可靠防火墙（人）。
- **建议**：
  1. **默认保持现状**（人工把脱敏后思路转发），把云顾问做成**便利层而非自动兜底**——即「一键生成脱敏草稿 + 预览 + 人点发送」，**人仍是出境闸**。
  2. 若实现，严格按 §五 七条硬约束 + level2 默认 + 意图门控 + fail-closed 泄露扫描 + 全量审计。
  3. **别让 loop 学会「卡就升级」**——升级要贵、要人批、思路要降权核验，保住本地探索能力与「离线/air-gapped」这个核心卖点。
- **一句话**：**云顾问值得作为「人工出境闸下的便利工具」存在，不值得作为「自动云兜底」存在。** 脱敏是降风险不是消除风险；在盗版 APK + 商业云 + 你自订红线的三重约束下，把「发不发」这个决定**留给人**，是唯一站得住的姿态。
