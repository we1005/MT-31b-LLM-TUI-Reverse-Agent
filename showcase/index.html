rev-agent 是一个自研轻量 TS/Bun agent CLI，驱动本地 Qwen3.6-35B-A3B MoE， 专做安卓 APK 只读逆向。它把用户手写的「4 阶段协议 + 7 铁律 + Token 预算」强制作 system 注入， 用结构化台账、SWA 稳定前缀、软化止损守卫补上弱模型的记忆/自律/长上下文短板。

设计红线

框架只做两件事，其余交还给 agent。

越过这条线，就退化成一条「反编译流水线」，丢掉 rev-agent 的独特价值（协议注入 + 深读裁量）。

①

按硬可观测事实注入 context。栈探测、案卷锚点、台账 —— 都是确定性事实，不是猜测。

②

按资源硬上限收 budget。ctx/步数/token 触顶才止损，且明确标注「资源上限」而非「任务完成」。

∅

永不替 agent 决定「下一步动作」或「任务是否完成」。守卫只注入 CHECKPOINT，决策权留给模型。

SWA 稳定前缀

台账拼 messages 末尾、system 逐字节静态 → llama.cpp KV 前缀可复用。实测前缀缓存 0% → 97%，治"越聊越卡"。

agent.ts · REV_GUARD_MODE
📒

带外结构化台账

每次 read/grep 后零-LLM 自动抽取 reads/greps/hops，verbatim 存类名行号，交叉核验打 ✓。绕开 SDK 配对 bug。

memory/ledger.ts
🛡️

signal 软化止损

守卫从"计数即强制收尾"改成"信号触发注入 CHECKPOINT + 给预算"，只在资源硬上限收尾。难题不再被过早掐停。

guards.ts · 默认 signal
🗂️

案卷 handoff

--corpus 接手强模型前置分析（去混淆映射 + file:line 锚点），把弱模型的"搜索题"降级成"核对题"。实测 6.8× 快。

corpus.ts · 锚点自检
🔐

脱敏云端顾问

本地卡住 → 台账驱动确定性脱敏 → 问云端拿方法论 → 还原续跑。fail-closed 泄露扫描，真实外网 0 泄露。默认关。

advisor.ts + redact.ts
🧭

主动栈探测

开局 unzip -l 看 lib/assets 指纹，权威识别 Unity/Flutter/RN/加固，掐掉模型"谎称无 native"的 false-negative。
