# 安卓逆向 · 保姆级系列教程 · 总纲与术语总表

> **写给谁**：懂 C/C++、后端、编译/链接/汇编/指针/系统调用,但**基本不碰安卓、不熟 Java/Kotlin/Dalvik/ART** 的工程师。
> **这套教程干什么**：以《MT & NP 管理器·全功能逆向分析总报告》为锚点,把报告里让你"一头雾水"的**每个术语、机制、产品、项目**,用你熟悉的概念类比、从零讲透。
> **合规**：全系列是**理解 + 检测 + 防御**向的技术科普——讲"这东西是什么、怎么工作、怎么在样本里认出、防御方怎么堵",**不提供"对某个目标 APK 动手破解"的操作步骤/命令**。

## 二、给 C++ 工程师的"一页对照表"(先建立直觉)
| 安卓世界 | C++/后端世界的类比 | 一句话 |
|---|---|---|
| APK | 一个 .zip 安装包 | APK 本质就是个 ZIP,改名 .zip 能直接解开 |
| DEX 字节码 | JVM 字节码 / .NET IL(不是机器码!) | 跑在虚拟机上的中间表示,**还原度极高**(jadx 几乎还原源码) |
| ART / Dalvik | JVM(带 GC 的托管运行时) | 执行 DEX 的虚拟机;ART 是新的,Dalvik 是老的 |
| smali | DEX 的"汇编",但比 x86 汇编可读得多 | 一条 smali ≈ 一条 dex opcode |
| .so 库 | 就是 ELF 共享库(`.so`) | native 机器码,逆向难度=你熟的 IDA 看汇编 |
| JNI | FFI / `extern "C"` 跨语言调用边界 | Java↔native 的桥,过一次边界有开销 |
| ClassLoader | 动态链接器(`dlopen`)+ 类加载 | 负责把 dex 里的类加载进内存 |
| 反射 (Reflection) | RTTI + 运行时按名字找符号并调用 | 运行时按字符串名操作类/方法/字段 |
| Application 类 | 进程入口的全局单例(比 `main` 更早的 init) | App 启动最先跑的对象,是注入的黄金位置 |
| `.super`(父类) | 基类 | "移花接木"改的就是它 |
| PackageManager | 系统的"包数据库"服务 | App 问它"我的签名是什么" |
| 签名 (Signature) | 代码签名(类似 Authenticode/GPG 签发布物) | 证明"这个包是谁发布的、没被改过" |
| Hook | 运行时改函数行为(类似 PLT/GOT 改写、LD_PRELOAD、detour) | 拦截并篡改一个函数的输入/输出 |
| 加壳 (Packer) | 加了自解密的 exe(运行时解密自身) | DEX 被加密,运行时才解密加载 |
| Dex2C / 方法原生化 | 把热点函数用 C 扩展重写(类似 Cython) | 把 Java 方法编译成 .so,原方法只剩空壳 |
| VMP / dex-VM | VMProtect | 把方法转成自定义字节码,跑私有解释器 |
